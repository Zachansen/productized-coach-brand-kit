# Productized Coach Brand Kit

Claude Code skill that applies the Productized Coach brand — logos, fonts, and colors — to any styled output (docs, slides, spreadsheets, HTML/React artifacts, posters).

## Install

Clone into your user-scoped skills folder:

```bash
git clone https://github.com/Zachansen/productized-coach-brand-kit.git ~/.claude/skills/productized-coach-brand-kit
```

Then reference this skill when you want brand-aligned output. Claude will auto-apply Libre Baskerville for headings, Work Sans for body, the green/neutral palette, and pick the right logo variant for the background.

## What's inside

- `SKILL.md` — the skill itself (fonts, colors, logo rules, per-file-type application)
- `assets/logos/` — Full + emblem logos in Dark Green, Jet, and White (SVG + PNG fallback)

## Brand at a glance

**Fonts**
- Headlines: Libre Baskerville
- Body: Work Sans

**Primary palette**
- Dark Green `#013121`
- Dark Spring Green `#1C6E42`
- Jet `#32312E`
- Seasalt `#F8F7F5`
- White `#FFFFFF`

See `SKILL.md` for the full spec including extended palette and per-format guidance.
